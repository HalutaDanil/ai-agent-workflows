# AI Agent Workflows

> Построение AI-агентов с помощью n8n

## О проекте

Проект по созданию автоматизированных AI-воркфлоу с использованием платформы n8n. Реализованы цепочки обработки данных, интеграция с LLM и автоматизация бизнес-процессов.

## Что реализовано

| Задача | Описание |
|--------|----------|
| `task2` | Базовый воркфлоу с триггером и обработкой |
| `task3` | Интеграция с внешним API |
| `task4` | Обработка данных из JSON |
| `task5` | Условная логика в воркфлоу |
| `task6` | Сложная многошаговая автоматизация |

## Архитектура воркфлоу

```
[Триггер] → [Обработка] → [LLM] → [Фильтр] → [Действие]
                ↓
         [Условная ветка]
                ↓
         [Логирование]
```

## Технологии

- **n8n** — платформа автоматизации
- **LLM API** — интеграция с языковыми моделями
- **JSON workflows** — конфигурация через JSON

## Файлы

- `My_workflow_in_task*.json` — экспортированные воркфлоу из n8n
- `task*.pdf` — документация по задачам
